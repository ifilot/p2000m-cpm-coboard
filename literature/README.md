# Historical source material

This directory contains the primary historical documents and the physical
motherboard PROM dump used while researching the co-board:

- `MW106 CPM Kaart.pdf`: documentation for the historical CP/M card.
- `P2000MT Field Support Manual.pdf`: Philips service information.
- `82s123_dump_mobo.bin`: 32-byte dump of a P2000M motherboard decoder PROM.

These files provide context, not the normative implementation. The tested CUPL
source under `cupl/` is authoritative. See `docs/memory-decoding.md` for the
consolidated interpretation.
